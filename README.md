Full-stack developer and computer science student. I like building things end to end — from the Android app or the web backend to the Raspberry Pi it runs on, putting the hardware pieces together into a system that does what I need.

**Currently**

- 🎓 Finished my bachelor's thesis — an RFID attendance terminal on Raspberry Pi (defended with grade A)

**Tech I work with**

| Backend / Web | PHP, REST APIs, MySQL, Python, Flask, SQLite, nginx |
| Desktop / Embedded | Python (pywebview, Tkinter), Linux, Raspberry Pi |
| Tools | Git, GitHub, Android Studio, LaTeX |

**Featured projects**

- 🪪 **RFID attendance terminal** — touch kiosk on Raspberry Pi (pywebview) with a Flask admin backend, SQLite and HTTPS behind nginx, plus a 3D-printed enclosure. *Repositories coming soon.*
